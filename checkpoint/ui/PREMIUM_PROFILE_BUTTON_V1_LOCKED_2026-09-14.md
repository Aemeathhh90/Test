# KakaAnime V1 — Premium Profile Button

Status: LOCKED
Date: 2026-09-14

## Decision
Do not add another Premium button to the Home quick-action/header area.

Use the existing Premium duration/status text in the profile header as the actionable Premium control.

### Free User
The existing Premium area becomes:
- `Upgrade Premium`
- Tapping it opens the Premium package selection screen.

### Premium User
The existing duration/status area becomes:
- `Premium aktif • 27 hari lagi` (example)
- This is tappable.
- Tapping it opens the Premium status/details screen.

## Badge
The `Premium` badge beside the nickname remains status/identity only and is not the main action button.

## Layout Goal
- No additional Premium button is added to Home.
- Keep the existing profile header compact.
- Avoid crowding the Home header.
- The same profile area communicates both Premium status and the available action.
