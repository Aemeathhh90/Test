# KakaAnime V1 — Diamond / Premium Header State

Status: LOCKED
Date: 2026-09-14

## Header Control
The Home header uses a compact pill-style status control.

### Free User
- Diamond icon + current Diamond count.
- Example: `💎 7.848`.
- When Diamond is 0, show `💎 0`.
- The control is tappable and opens the Diamond information surface.

### Premium User
- Do not show a Diamond balance as the primary status.
- Show an Unlimited state instead.
- Example: `∞ Unlimited`.
- Premium users have unlimited episode access and do not consume Diamonds.
- The control is tappable and opens the Premium information surface.

## Diamond Meaning
- Diamond is an episode-access mechanism, not a wallet/top-up system.
- 1 Diamond = 1 episode.
- There is no Diamond Top Up page in V1.
- There is no button for saving/collecting Diamonds in the header.
- Rewarded ads are only requested when a free user attempts to watch an episode with 0 Diamonds.

## Visual Direction
- Compact rounded pill.
- Dark-first KakaAnime styling.
- Subtle border and accent treatment.
- Keep the control visually consistent with the Home header reference.
