# KakaAnime V1 — Premium UI Reference

Status: LOCKED
Date: 2026-09-14

## Reference Direction
The user approved the generated KakaAnime Premium UI concept as the visual reference for V1.

## Free User → Premium
Premium upgrade screen should contain:
- Premium hero/banner with KakaAnime anime artwork.
- Premium package selection: 1, 3, 6, and 12 months.
- Price and savings labels where applicable.
- Clear selected-package state.
- Premium benefits section.
- Primary `Upgrade Premium` action.

## Premium User → Premium Aktif
Active Premium screen should contain:
- `Premium User` identity/status badge.
- `∞ Unlimited` as the main access state.
- `Premium aktif • 27 hari lagi` as an example remaining-duration state.
- Start date and expiry date.
- Active Premium benefits.
- Compact subscription/status card.

## Locked Product Separation
- Diamond and Premium are separate systems.
- Diamond is the Free-user episode-access mechanism.
- Premium provides unlimited episode access and does not consume Diamonds.
- Do not add Diamond Top Up to Premium UI.
- Do not add a separate Premium button to Home; use the existing profile Premium status/duration control as the entry point.

## Visual Direction
- Dark-first.
- KakaAnime purple/blue accent treatment.
- Rounded modern cards.
- Anime artwork used selectively for hero/status cards.
- Compact enough for mobile; avoid unnecessary screens or feature clutter.

## Scope Note
This checkpoint records the approved UI/UX reference only. It does not claim that the Premium screens have been implemented or that payment/billing is active.
